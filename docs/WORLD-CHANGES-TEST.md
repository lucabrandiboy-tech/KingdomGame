# Testing: easier ages, dark nights, brighter lights, no stumps

Run **KingdomGame > Build Game Scenes** first: it updates your settings.

- **Ages are 3 times easier**: research to each age costs a third of before (the Bronze Age:
  3,333 wood and stone, 1,000 food, 166 copper) and takes a third of the time (8 hours of real
  time for the first, up to 56 hours for the last). Check the tech screen (T).
- **Nights are pitch black**: at night you only see what a light shows (your own light, fires,
  torches, lamps). Day Night Config > Night Brightness sets it (0 = black).
- **Lights reach twice as far**: braziers, torches and the electric lamps light about 10 tiles
  instead of 5 (Day Night Config > Fire Radius).
- **No stumps**: a wild tree cut down disappears completely, so nobody (zombies included) bumps
  into stumps. Stumps in an older save disappear when it loads. Planted trees (tree farms,
  saplings) still grow back where they stood.
